Twilio Telephony & Public Tunnel Setup

To receive real phone calls on your Twilio virtual number, expose this local server to the internet using the bundled Cloudflare Tunnel or ngrok.

Step 1: Launch Cloudflare Tunnel

.\cloudflared.exe tunnel --url http://localhost:8765

Step 2: Configure Twilio Phone Number Webhook

In your Twilio Console, set the Voice Webhook for your phone number to:

https://<GENERATED_CLOUDFLARE_DOMAIN>.trycloudflare.com/voice/incoming  (HTTP POST)

Or run the automated script:

.venv\Scripts\python.exe scripts/setup_twilio_webhook.py https://<DOMAIN>.trycloudflare.com/voice/incoming
